# `sim/tests/data/` — golden fixtures the tests read rather than build

Data a test asserts *against*, kept out of the test file so the fixture and the assertion
can be reviewed separately — and so a golden can be regenerated by a tool without anybody
editing a `.py`.

- **`ext_conformance.json`** — the conformance golden set for
  [sandboxed content extensions](../../../docs/architecture/backlog/sandboxed-extensions.md)
  (BEYOND #6). Six rows, `G1`–`G6`, each `(ast, facts, seed, clock, grants,
  expected_effects, explain, grant_list)`: **all six of OpenMoxie's executable content
  hooks, hand-ported into our AST**.

  It is three things at once, which is why it is a file and not a fixture:

  1. **The proof the language is expressive enough.** Upstream's entire executable content
     library is 6 `code` strings / 9 hooks / 4 modules, and not one of them iterates. If
     our grammar expresses these six, it expresses the state of the art — which is the
     load-bearing premise of the brief's §3.2 choice.
  2. **The regression suite.** [`test_ext.py`](../test_ext.py) reproduces every row byte
     for byte. Four rows are `xfail(strict)` because they declare `act`/`subscribe`/`brain`,
     which P0 refuses at load (the `RemoteChatAction` wire is not plumbed — brief S5);
     their *grammar* is asserted valid today, so the day the wire lands they turn green
     rather than needing to be written.
  3. **The cross-host contract.** P1 adds a JavaScript evaluator for the Cloudflare
     Worker; it must reproduce this same file in `workerd`. That is why `format` takes an
     explicit spec and `keys` sorts — no language's default float repr or dict order ever
     reaches an effect.

  Regenerate with [`../../tools/build_ext_conformance.py`](../../tools/build_ext_conformance.py).
  The file is committed, and the test reads the **file** rather than the generator, so a
  bug in the generator cannot quietly rewrite the goldens it is supposed to be checked
  against.

  **Clean-room:** these are *re-authored programs*, never upstream source. OpenMoxie is
  MIT, © Justin Beghtol, cited by hook name in the brief's §8 table and in
  [`ATTRIBUTION.md`](../../../ATTRIBUTION.md); a test asserts no Python-ism travelled into
  this file with them.
