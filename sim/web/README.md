# 🌐 sim/web — the static site and the 3D Moxie

The simulator front-end: a three.js model of Moxie with a 7-DOF rig matching the real motors,
plus the hub, setup, cloud-console and docs pages. [`bridge/`](bridge/README.md) drives the model
live over MQTT; the by-hand control panel works with no bus at all.

## Run it

```sh
python3 sim/serve.py 8080    # from the repo root; then open http://localhost:8080/
```

`sim/serve.py` serves `/sim` as `sim.html`, as Cloudflare Pages does (the hub links `/sim`,
because Pages answers `sim.html` with a 308), and so does the Docker stack's nginx
([`../nginx.conf`](../nginx.conf)). Any other static server works too, fully offline, if you open
`sim.html` by name: every library and font is vendored in [`vendor/`](vendor/README.md).

## `window.moxie` API

A `moxie-ready` CustomEvent fires on `window` with the API in `event.detail`.

```js
moxie.setMotor(index, value)     // 0..32767 (16384 = center), animates to target
moxie.getMotor(index)            // current smoothed position (idle liveness excluded)
moxie.setFace(expression)        // any of moxie.expressions, or "blink"
moxie.setSpeech(text)            // speech bubble + mouth flap
moxie.setMouthOpen(0..1) / getMouthOpen()
moxie.setHeartLED(on, "#ff5577")
moxie.showIcons([...]) / clearIcons()   // up to 4 badges
moxie.centerAll() / setIdle(bool) / isAlive() / isUserHeld(i)
moxie.setSceneLight(0..1) / setShowAxes(bool)
```

Motor indices (source of truth: `MOTOR_DEFS` in [`moxie/config.js`](moxie/config.js)):
0/2 left/right shoulder up-down, 1/3 left/right shoulder in-out (the spring elbow folds from
this axis; elbows have no motor), 4 head tilt, 5 body yaw, 6 body lean. Values map piecewise-linearly
to angles, so center is always the rest pose.

## Gotchas

- **Mode, not hostname.** `offline` (no `/api/health`) is byte-identical to the plain static site and never re-polls; `degraded` shows the reason; `live` only once `cloud-transport.js` is loaded. Poll backoff honours `Retry-After`, else 30 s doubling to 5 min, never while `document.hidden`. `#bus-connect` keeps `needs-backend` in every mode.
- **Server voice.** `voice/cloud.js` decodes `CloudTTSResponse` itself (base64 int16 PCM, no `decodeAudioData`) and starts chunks of one `event_id` strictly in `chunk_num` order; a missing chunk is written off after `TTS_GAP_MS` (1200 ms) and an event closes `TTS_EVENT_MS` (5000 ms) after draining. `lastPlaybackStats()` records the start order for tests.
- **`#tts-status` has one owner** (`voice/cloud.js`); others call `moxieAudio.setTtsHint()`.
- **Scripts are same-origin, no `defer`/`async`**, so `script-src` needs no `'unsafe-inline'`. Every app script needs a `no-cache` rule in `_headers` (subdirectories: one `/dir/*` rule), enforced by `sim/test_csp.mjs`; the importmap hash comes from `../tools/build_csp_hashes.py`. `_headers` does not apply to Pages Function responses (`functions/api/_lib/envelope.js` sets those).
