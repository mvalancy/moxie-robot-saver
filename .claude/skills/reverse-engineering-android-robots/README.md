# 🛠️ Reverse-engineering an Android-computer robot — the playbook

Master playbook for reverse-engineering an Android-computer robot or appliance (RK/Qualcomm SoC + an Android app + often an MCU/DSP + a cloud protocol) toward clean-room docs and a revival toolkit. Use when starting to RE a new device like this, or to orient before diving into firmware/apps/native-libs/protocol/hardware. Moxie is the worked example.

Invoke it by name (`reverse-engineering-android-robots`) — it is a **shared agent skill**, so any agent working in this repo can load it instead of re-deriving the method.
