# 🤝 Shared Claude agents & skills

Claude-compatible agents and skills that ship with the repo, so the Moxie knowledge travels with the code
instead of living on one laptop. Open the repo in [Claude Code](https://claude.com/claude-code) (or any
Claude Agent SDK harness) and these load automatically. Every helper points at the source-of-truth docs
(`docs/reverse-engineering/`, `docs/architecture/`, `docs/guides/`), so when the docs improve, the
helpers improve. Improvements welcome — send a PR.

| Folder | What's in it |
|---|---|
| [`agents/`](agents/README.md) | Two specialists to delegate to: `moxie-revival-guide` (owners) and `moxie-protocol-expert` (developers). |
| [`skills/`](skills/README.md) | 14 task recipes invoked by name: using Moxie, reverse-engineering any Android robot, and running a long project with agent loops. |

The narrative that ties the reverse-engineering skills together is
[`docs/reverse-engineering/PLAYBOOK.md`](../docs/reverse-engineering/PLAYBOOK.md).
